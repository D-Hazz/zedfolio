SerreConnect

Smart greenhouse automation built around sensor-driven decisions, environmental monitoring, and practical field usage.

Overview

SerreConnect demonstrates how connected devices and data can be transformed into actionable plant-health insights. The system is designed to monitor environmental conditions and make automation more understandable for operators.

I approached it as a full embedded product concept: sensing, interpretation, automation, and interface clarity all working together.

  • Sensor-based climate tracking
  • Remote monitoring dashboards
  • Automation logic for greenhouse use cases
