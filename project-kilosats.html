Case study

Kilosats

A smart energy and payment concept combining embedded telemetry, real-time monitoring, and Bitcoin Lightning-enabled access control.

Overview

Kilosats explores how electricity and digital value can be tracked and exchanged in a more transparent, automated way. The concept connects sensors, a smart metering flow, and a wallet-driven payment layer to support usage monitoring and settlement.

The project reflects the broader direction of my work: embedded software, payment systems, and product design tightly connected through a real technical workflow.

  • Real-time energy and device monitoring
  • Lightning-style payment flow and access verification
  • Clean product interface for usage data and controls

Project snapshot

Type: IoT + financial product Stack: ESP32, sensor logic, web interface Focus: Smart metering and value exchange
